## The one thing left that development cannot do

The app is installed and running, but **it has never been launched from the Mac's
GUI session** — every launch so far came from an SSH command, and macOS attributes
the process to `sshd-keygen-wrapper`. Consequences, all observed:

- Its permission requests are attributed to the SSH session, so macOS never records
  `kTCCServiceListenEvent` for `com.aimetaphd.shortcutsense` (the system `TCC.db`
  has only an Accessibility row, value 0).
- Therefore the Input Monitoring pane has nothing to switch on for this app.
- `--diagnose` run over SSH reports the SSH session's grants, not the app's.

**The fix is one human action:** on the Mac, open ShortcutSense from Finder or the
Dock (or `open /Applications/ShortcutSense.app` from a Terminal window in the GUI
session), then answer the two permission prompts. After that, `--diagnose` from that
same Terminal gives the app's real values.

## Defects found and fixed while building

Seventeen, listed in `docs/qa/defects.md`. Eleven came from an independent code
review added before packaging; three of those were release-blocking and silent:

- **D-001** — hotkey presses were counted twice (handler and activation observer).
- **D-006** — Secure Input and lock state came from a 2-second poll, so a password
  field gaining focus between polls could still have counted keystrokes.
- **D-007** — CGEventFlags were reinterpreted as Carbon bits. The two layouts share
  no bits, so **no shortcut was ever captured** and every activation looked like
  `unknown_origin`, while keystroke totals looked healthy.
- **D-008** — deleting all data left OS hotkeys registered, so they kept launching
  apps and writing rows for a deleted shortcut.
- **D-009** — a failed unregister dropped the record, orphaning an OS grab that
  could no longer be undone.

Two more were completeness defects that would have made a claimed feature unusable:

- The AI layer had no real HTTP transport (only a test double).
- `docs/release/` was silently excluded by an unanchored `.gitignore` rule, so the
  acceptance matrix was never committed.
