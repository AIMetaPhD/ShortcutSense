## 3. 已知的环境事实

- 自签名证书私钥在 `~/ss-cert/ss.keychain`，密码在 `Scripts/make-cert.sh` 的注释里。
  这是本地开发便利，不是发布级安全；删掉它会让签名退回 ad-hoc，**已授予的 TCC
  权限会因重建失效**。
- Muse 是无人值守 Linux worker，没有 macOS 桌面，只能做静态审阅。
- 公开前必须重跑脱敏：`python Tools/sanitize.py`，再按 `Tools/sanitize-history.md`
  检查历史与提交信息。
